
# 🌾 Agriculture Crop Marketplace Dashboard

## Project Overview
This project is an interactive agriculture analytics dashboard developed using Python, Streamlit, Pandas, and Plotly.

It helps users explore crop production, yield patterns, rainfall, fertilizer usage, and agricultural market prices.

## Objectives
- Analyze crop yield trends over time.
- Compare agricultural productivity across regions.
- Explore the relationship between rainfall and crop yield.
- Examine monthly market price trends and price variability.
- Compare crop production with market prices.
- Explore fertilizer usage and crop yield patterns.

## Dashboard Features
1. Crop yield trend over years
2. Top 15 regions by yield
3. Rainfall vs. yield
4. Monthly market price trend
5. Price variability by crop
6. Production vs. market price
7. Crop productivity comparison
8. Fertilizer use vs. yield

Additional features include interactive filters, KPI cards, data previews, and CSV downloads.

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly
- OpenPyXL

## How to Run Locally
1. Install the required packages:

   `pip install -r requirements.txt`

2. Run the dashboard:

   `streamlit run app.py`

3. Upload the Excel workbook through the dashboard interface.

## Dataset Privacy
The Excel workbook is not included in this repository. Users must upload the workbook through the dashboard to view the analysis.
